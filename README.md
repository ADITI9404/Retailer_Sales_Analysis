# 🛍️ Retailer Data Analysis

An end-to-end **Retail Data Analysis project** using **Python, MySQL, and Power BI** to analyze customer behavior, product performance, sales, and order operations.

## 🛠️ Tools & Technologies

* Python — Pandas, NumPy, Matplotlib, Seaborn
* MySQL — SQL analysis and business queries
* Power BI — Dashboard, DAX & KPI reporting
* Excel — Data inspection and validation

## 📊 Dataset

* **300,000+ records**
* **30 columns**
* Transaction data from **2023–2024**
* Includes customer, product, sales, payment, shipping, feedback, and order information.

**Dataset:** [Retail Customer Transaction Dataset](https://www.opendatabay.com/data/consumer/327c5b3c-9f40-45bb-a79b-d5e2c9abc68a?utm_source=chatgpt.com)

## 🔍 Project Workflow

```text
Raw Data → Data Cleaning → EDA → SQL Analysis → Power BI Dashboard
```

## 🐍 Python Analysis

* Cleaned and validated the dataset
* Handled missing values and duplicates
* Performed exploratory data analysis
* Analyzed customer, product, and sales trends

## 🗄️ SQL Analysis

Performed business queries to analyze:

* Top customers and products
* Revenue and purchases
* Product categories
* Order status
* Payment and shipping methods

## 📈 Power BI Dashboard

Created an interactive multi-page dashboard covering:

* **Executive Sales Overview**
* **Customer Analysis**
* **Product Analysis**
* **Order & Operations Analysis**

Key KPIs include **Revenue, Purchases, Customers, Average Purchase Amount, Completed Orders, Cancelled Orders, and Cancellation Rate**.
